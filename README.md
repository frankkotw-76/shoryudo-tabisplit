## 🪙 多幣別公積金（日幣現鈔池 & 台幣公費池）

旅行中大家常會同時有「日幣現金公費」（日本現場吃飯買門票）與「台幣公費」（出發前在台灣預收 KKday 乘車券、租車保險、WiFi 機費）。

系統現已支援**雙幣別獨立核算**：

1. **雙公費池即時儀表板**：
   - 🇯🇵 **日幣現鈔池**：即時顯示日幣現金餘額（收、支、餘）。
   - 🇹🇼 **台幣公費池**：即時顯示台幣帳戶餘額（收、支、餘）。
   - 💱 **折合總值**：依當前匯率自動顯示雙幣別公費的等值台幣總資產。

2. **➕ 存入公積金 (入帳)**：
   - 選擇 **🇯🇵 日幣 JPY** 或 **🇹🇼 台幣 TWD**。
   - 支援「6人均收」（提供快速按鈕：日幣 `¥10,000`、`¥20,000` 等；台幣 `NT$ 1,000`、`NT$ 3,000` 等）或「個別補繳」。

3. **💸 記錄公積金支出 (扣款)**：
   - 可自由切換「從【日幣現鈔池】扣款」或「從【台幣公費池】扣款」。
   - 輸入當下即時提示該幣別剩餘餘額。

4. **🏁 雙幣別退款試算**：
   - 旅程結束時，自動計算：
     - 日幣現鈔每人退還：`¥ X / 人`
     - 台幣帳戶每人退還：`NT$ Y / 人`
   - **一鍵「複製 LINE 退款通知」**，文字直接貼進群組！
